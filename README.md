# ТЁМНОЕ ДЕЛО · платформа для городских историй

**Рабочая MVP-сборка, а не запущенный коммерческий сервис.** База: утверждённый 3D-стиль, логотип, 40 городских дел, автоматический слайдер, городские страницы и первые игровые задачи. Добавлены сервер, аккаунты, права доступа, редакционный чат, заказы, схема выплат авторам.

## Быстрый запуск на Windows

1. Распакуйте ZIP полностью в отдельную папку.
2. Установите Python 3.11+ с сайта python.org, при установке включите `Add Python to PATH`.
3. Дважды нажмите `start-windows.bat`.
4. Перейдите на **http://127.0.0.1:8000**. Не запускайте `index.html` двойным щелчком: в этом случае серверные функции оплаты, входа и чата работать не будут.
5. Для телефона, подключённого к той же Wi-Fi сети: узнайте IP компьютера через `ipconfig` и откройте `http://IP-КОМПЬЮТЕРА:8000` (при необходимости разрешите доступ в брандмауэре Windows). Это локальная тестовая сеть, не публичный HTTPS-сайт.
6. Для демонстрации создайте аккаунт, выберите первый бесплатный город, второй откройте через кнопку **«Тестовая оплата»**. Реальные деньги в локальном тесте не списываются.

В Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export APP_ENV=development TD_DEMO_PAYMENTS=1 PUBLIC_BASE_URL=http://127.0.0.1:8000
uvicorn server:app --host 127.0.0.1 --port 8000
```

## Что работает

- Аккаунты с хешированием паролей и HttpOnly-сессиями.
- **Первый выбранный город бесплатно** на пользователя (право сохраняется в БД). Выбор не навязывается Новороссийску, доступны все 40 городов.
- **Следующие официальные городские дела по 110 ₽**; цену задаёт сервер, а не браузер.
- Отдельные страницы городов, интерактивная первая глава и сохранение игрового прогресса в браузере.
- Автор может бесплатно **предложить новое дело**, добавить ссылку на источник и переписываться в чате редакции.
- **1 000 ₽ за разработку интерактивной истории** после предложения, отдельный оплачиваемый заказ.
- Автор выставляет цену на свою опубликованную историю (от 50 до 10 000 ₽).
- При покупке: **90% начисляется автору, 10% остаётся площадке** в копейках, с защитой от повторной обработки платежа.
- Публикация истории только после оплаты разработки и редакционной проверки.
- ЮKassa: создание реального платежа, webhook с проверкой по API, «Безопасная сделка» для авторских продаж, подготовленный вывод выплаты по токену провайдера. Никакие данные банковских карт не сохраняются.
- Локальный деморежим, чтобы проверить весь путь без платежных реквизитов.

## Что нужно сделать перед реальным приёмом денег

1. Получить юридически оформленный аккаунт ЮKassa, **подключить «Безопасную сделку»** отдельным договором, получить `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`. Пока договор не заключён, продажи авторских историй в production блокируются.
2. Настроить HTTPS, `PUBLIC_BASE_URL`, `APP_ENV=production`, `TD_DEMO_PAYMENTS=0`, секрет `TD_PAYOUT_ENCRYPTION_KEY` и постоянную базу данных на диске. **На Render без диска SQLite может потеряться при следующем развертывании.** Рекомендуется Postgres для масштабирования; текущий MVP использует SQLite и один процесс.
3. Указать `ADMIN_EMAIL` до регистрации редактора. Роль назначается только на момент его регистрации. Использовать настоящий адрес редакции.
4. Настроить в личном кабинете ЮKassa HTTPS-уведомление `payment.succeeded` → `https://ваш-домен/api/webhooks/yookassa`. Проверить реальные и тестовые платежи, возвраты, вебхуки, чеки 54-ФЗ.
5. Авторы подключают карту через защищённый виджет ЮKassa. Для выплаты редактор использует `POST /api/admin/payouts/{order_id}/send`, затем `verify`. Выплаты **не отправляются автоматически, пока не подключён процесс редакционной сверки и договор**; начисление на внутреннем балансе ≠ получение средств на карте.
6. Учесть, что комиссия ЮKassa и НДС на неё удерживаются из **доли площадки**: 10% это доля *до* эквайринга и налогов, а не чистая прибыль.
7. Подготовить и опубликовать оферту, условия размещения пользовательских историй, политику конфиденциальности, правила возврата, авторские права/лицензии, юридические данные продавца, порядок налогового учёта и антифрод/обработку жалоб.
8. Получить права на изображения или заменить ссылочные фото собственными/с подходящей лицензией. Нельзя автоматически объявлять городскую легенду доказанным происшествием.
9. Перед публичным запуском добавить подтверждение email, восстановление пароля, rate limiting, мониторинг, резервное копирование, полноценные тесты редких/ошибочных платежных состояний и журнал аудита.

**Не загружайте реальные пароли, банковские карты или ключи ЮKassa в чат.** Используйте секретные переменные хостинга.

## Примечание по игровому контенту

Все 40 городов и игровые прологи доступны. Это ещё не 40 полноценных расследований на 1–2 часа с 50 уникальными уликами; для каждого дела требуется отдельная историческая и игровая редактура. Чат позволяет собирать новые сюжеты, но редактор должен проверять факты и права на публикацию.
